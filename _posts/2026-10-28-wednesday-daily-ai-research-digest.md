### 1. ChronoReplay: One Answer Interface Is Not Enough for Streaming Spatial Intelligence

[Read Paper](https://huggingface.co/papers/2610.34283)

ChronoReplay mitigates interface lock-in in spatial vision-language models by replaying heterogeneous spatial supervision chronologically, improving cross-task transfer and enabling efficient inference-time evidence selection.

### 2. Multiscale Policy Optimization for Long-Horizon LLM Agents

[Read Paper](https://huggingface.co/papers/2610.35013)

Multiscale Policy Optimization improves long-horizon agent training by aligning credit assignment and policy updates at the turn scale.

### 3. The Trinity:Capability-Driven Recursive Self-Improvement for Multimodal Agents

[Read Paper](https://huggingface.co/papers/2610.36077)

The Trinity framework recursively improves multimodal agents by organizing tasks into a capability tree, generating simulated training worlds, and routing specialized harness modules to boost performance on diverse benchmarks.

### 4. VibeVideoBench: Evaluating Multimodal Agents on Code-Driven Video Generation

[Read Paper](https://huggingface.co/papers/2610.35864)

VibeVideoBench evaluates multimodal agents that generate videos via code, finding that top systems meet core requirements on most tasks but frequently fail due to poor time management.

### 5. PDRVLA: A Vision-Language-Action Model with Physical Dynamics Representations

[Read Paper](https://huggingface.co/papers/2610.37381)

PDRVLA improves robot action generation by integrating a lightweight physical dynamics module that predicts future visual features with world-model supervision, avoiding online video generation latency.

### 6. Hy-Nomas: Towards Free-form Interactive World Generation

[Read Paper](https://huggingface.co/papers/2610.36729)

Hy-Nomas is a video world model that uses causal attention and structured conditioning to generate interactive, multi-turn video segments with text and camera control.

### 7. Memory Tax: Dissecting the Net Value of Agent Memory

[Read Paper](https://huggingface.co/papers/2610.34073)

Large-scale evaluation reveals that dedicated memory systems often underperform naive retrieval-augmented generation, introducing a framework of memory benefit and memory tax to assess net value.

### 8. Can Discrete Tokens Serve as Semantically Lossless Representations of Visual Signals?

[Read Paper](https://huggingface.co/papers/2610.37662)

Factorized Vector Quantization improves discrete visual token quality by using parallel codebooks on complementary feature views, enabling discrete representations to match continuous ones in multimodal understanding.

### 9. HABIT-Bench: Evaluating Habit Induction from Longitudinal Weak Evidence in Agent Memory

[Read Paper](https://huggingface.co/papers/2610.24520)

HABIT-Bench evaluates whether LLM agent memory systems can infer implicit user habits from sparse dialogue evidence and apply them correctly across long-term interactions.

### 10. Rollback: Experience Backtracking in World Models for Policy Improvement

[Read Paper](https://huggingface.co/papers/2610.36068)

Rollback improves robot policies by using world models to rewind to past decisions, explore counterfactual actions, and generate fine-grained supervision, while continuously refining dynamics via real-world feedback.
