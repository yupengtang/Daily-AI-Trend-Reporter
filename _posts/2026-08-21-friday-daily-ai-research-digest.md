### 1. EnvHarness: Awakening Static Worlds for Agent Learning

[Read Paper](https://huggingface.co/papers/2608.19880)

EnvHarness and EnvRigger dynamically reshape static environments via programmable plugins to target agent weaknesses and improve reinforcement learning co-evolution.

### 2. FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis

[Read Paper](https://huggingface.co/papers/2608.18580)

FACET constructs executable terminal tasks by preserving source intent and grounding instructions, solutions, and verifiers in a shared repaired environment to enable scalable agent training.

### 3. SWE-bench Science: Can Coding Agents Resolve Engineering Tasks in Science?

[Read Paper](https://huggingface.co/papers/2608.19799)

SWE-bench Science benchmarks coding agents on scientific software repair, revealing failure mechanisms and mixed effects of scientific guidance.

### 4. 4DAnyone: Create Anyone in 4D from a Casual Monocular Video

[Read Paper](https://huggingface.co/papers/2608.20335)

4DAnyone reconstructs 4D humans from monocular video by generating multiview-consistent videos and lifting them into 4D Gaussian Splatting, using reference and target context designs to overcome scaling bottlenecks.

### 5. WithEveryone: Unified Planning and Identity Grounding for Group Image Generation

[Read Paper](https://huggingface.co/papers/2608.20336)

WithEveryone enables reliable identity-preserving group image generation for up to ten people by grounding identities to layout plans and using region-based identity losses.

### 6. MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use

[Read Paper](https://huggingface.co/papers/2608.20202)

Retrieved memories can induce reasoning errors and belief distortions in large language models, and an inference-time strategy helps avoid these cognitive traps while maintaining benchmark performance.

### 7. SkillEvo: Self-Renewing Evolution Gradients from Multi-Turn Interaction Feedback

[Read Paper](https://huggingface.co/papers/2608.13120)

SkillEvo improves agent skills through multi-turn feedback and active governance to sustain evolution gradients.

### 8. ForgeWM: Progressive Causal Training for Few-Step Action-Conditioned Video World Models

[Read Paper](https://huggingface.co/papers/2608.14022)

ForgeWM progressively distills bidirectional video generators into efficient few-step interactive world models with aligned discrete and continuous controls, supporting low-latency interaction and replay-time refinement.

### 9. Repo0: Design-Driven Zero-to-All Code Generation

[Read Paper](https://huggingface.co/papers/2608.19854)

Repo0 uses a dual-graph architectural state and modularity-guided structural evolution to generate complete software repositories from natural-language requirements with high functionality coverage.

### 10. FlashPrefill V2: Block-Sparse Prefill Attention for Long-Context LLM Serving

[Read Paper](https://huggingface.co/papers/2608.19758)

FlashPrefill V2 improves long-context serving via mean-corrected sparse attention, optimized GPU operators, and framework integration, achieving large speedups over dense baselines.
