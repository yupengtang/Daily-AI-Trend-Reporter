### 1. Trajectory2Gym: Decision-Grounded Compositional Interaction Synthesis for Tool-Use Agents

[Read Paper](https://huggingface.co/papers/2610.33568)

Trajectory2Gym improves tool-use training by constructing interactions with compositional coverage and decision grounding rather than collecting successful trajectories.

### 2. StreamVibe: Proactive Video Agents for Evolving User Intent

[Read Paper](https://huggingface.co/papers/2610.34662)

StreamVibe introduces a benchmark, streaming vision-language model, and hierarchical memory harness to enable proactive, intent-aware interaction with implicit and evolving user goals.

### 3. Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution

[Read Paper](https://huggingface.co/papers/2610.32285)

TraceTrial-Bench evaluates agent harness reliability across seven components using mechanism-oriented tasks, trajectory tracing, and failure attribution to compare harness designs and diagnose failures.

### 4. DynaFlow: Learning Free-Form Multi-Agent Orchestration

[Read Paper](https://huggingface.co/papers/2610.34467)

DynaFlow enables adaptive multi-agent collaboration by letting a main agent synthesize executable workflows that coordinate sub-agents through structured execution and verification.

### 5. InteractiveWorld: A Verifiable Human-Centric Environment for Building Better Interactive MLLM Assistants

[Read Paper](https://huggingface.co/papers/2610.33966)

InteractiveWorld provides a verifiable simulation environment and benchmark to evaluate whether multimodal language models can reliably guide humans through physical tasks.

### 6. Work Agents: Systems, Capabilities, and Optimization

[Read Paper](https://huggingface.co/papers/2610.35845)

The paper proposes a unified framework for work agents that integrates foundation models with runtime harnesses to execute complex digital tasks reliably, introducing dimensions of persistence and openness alongside capability families and evaluation metrics.

### 7. Continual Learning Exam: Benchmarking Long-Horizon RSI and Experiential Learning in LLM Agents

[Read Paper](https://huggingface.co/papers/2610.33956)

A new benchmark evaluates whether LLM agents improve through repeated professional tasks with feedback, revealing limited sustained learning in current frontier models.

### 8. WorldCast: World-Consistent Character Video Generation with Large-Angle Camera Control

[Read Paper](https://huggingface.co/papers/2610.33135)

CLACT and WorldCast enable consistent character video generation under large-angle camera motions by combining 3D point-cloud guidance with geometry-aligned memory attention.

### 9. Spatial Audio Generation and Editing with Executable Plans and Self-Distilling Transfusion

[Read Paper](https://huggingface.co/papers/2610.34415)

AMBIT is a unified framework that generates and edits first-order ambisonics audio by coupling autoregressive scene planning with rectified-flow rendering, using a specialized continuous VAE and on-policy self-distillation to preserve spatial structure and acoustic fidelity.

### 10. AV-FABLE: Audio-Visual Manipulation Forensics in Long-Form Videos

[Read Paper](https://huggingface.co/papers/2610.33413)

AV-FABLE introduces a long-form audio-visual benchmark for sparse manipulations, showing that frozen perception features of audio-visual large language models contain forensic evidence best recovered via separate temporal decoders rather than language outputs.
