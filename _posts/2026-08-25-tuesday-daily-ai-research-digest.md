### 1. Apodex 1.1: Scaling Agentic Intelligence for Complex Work

[Read Paper](https://huggingface.co/papers/2608.23283)

Apodex 1.1 improves sustained, verifiable progress on complex real-world tasks by scaling executable environments and training agents to coordinate long-horizon work with state maintenance and recovery.

### 2. EchoWM: Open and Enterable Omnimodal World Models

[Read Paper](https://huggingface.co/papers/2608.23189)

EchoWM is an omnimodal world model that generates synchronized high-resolution video, sound, music, and speech while following continuous 6-DoF navigation trajectories across first- and third-person views.

### 3. TLive-Omni: An Omni-Modal Understanding Model for E-Commerce Live Streaming

[Read Paper](https://huggingface.co/papers/2608.20958)

TLive-Omni is an omni-modal model for live-commerce that unifies image, video, audio, and text via timestamped token grouping, staged supervised training, and reinforcement fine-tuning with verifiable feedback to enable accurate real-time understanding.

### 4. Unlocking the Potential of Image Editing via Concept Scaling and Dense Supervision

[Read Paper](https://huggingface.co/papers/2608.16812)

A hierarchical taxonomy and dense supervision strategy improve diffusion-based image editing through fine-grained concepts, large-scale paired data, and granular evaluation.

### 5. MobilePA-Bench: Benchmarking Mobile Planner Agents on Complex Real-World Tasks

[Read Paper](https://huggingface.co/papers/2608.23035)

MobilePA-Bench is an interactive sandbox benchmark that evaluates mobile planning agents on tool-calling, sub-agent collaboration, memory usage, and composite skill invocation under real runtime constraints.

### 6. Prime Agent: A Self-Improving RLM Harness

[Read Paper](https://huggingface.co/papers/2608.23552)

Prime Agent is an open-source harness that uses recursive subagents, persistent computation, and agent-to-agent coordination to extend language models' long-horizon capabilities across coding and reasoning tasks.

### 7. Block3D: Efficient Text-to-3D Generation via Block-Wise Diffusion

[Read Paper](https://huggingface.co/papers/2608.19567)

Block3D accelerates text-to-3D generation by using block-wise diffusion with confidence-guided correction to reduce inference time while preserving geometric fidelity.

### 8. RISE: Adaptive Imagination for World Action Models

[Read Paper](https://huggingface.co/papers/2608.20430)

RISE adaptively decides when to continue or stop imagination rollouts for planning by weighing expected benefit against cost, supported by a counterfactual driving dataset with expert annotations.

### 9. Towards a Densing Law for User Representation Learning at Billion-Scale Capacity

[Read Paper](https://huggingface.co/papers/2608.23392)

The study proposes a scaling law linking data size to tokenization capacity for user behavior modeling and introduces an adaptive tokenization method to improve efficiency.

### 10. ARC: Fair Relative Advantage Comparison in Open-Ended Real-World Interaction

[Read Paper](https://huggingface.co/papers/2608.13622)

ARC improves fairness in group-based reinforcement learning for open-ended agents by conditioning rollout comparisons on strategy, enabling more context-appropriate behavior in responsive user-agent interaction.
