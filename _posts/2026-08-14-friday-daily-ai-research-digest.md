[Read Paper](https://huggingface.co/papers/2608.13546)

Evoke is an interactive world model that uses external persistent memory and a redesigned long-horizon teacher to enable responsive, open-ended video generation with bounded context and low latency.

### 2. DreamX-Phi 1.0: Action-Conditioned Video World Model for Robotic Manipulation

[Read Paper](https://huggingface.co/papers/2608.13489)

DreamX-Phi 1.0 is an action-conditioned video world model for robotic manipulation that uses geometric attention encoding, depth estimation, object masks with a frozen teacher, and distillation to generate faithful future observations.
