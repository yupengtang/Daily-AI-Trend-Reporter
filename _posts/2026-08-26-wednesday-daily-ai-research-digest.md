### 1. Annotations as Rollouts: Efficient and Scalable Reinforcement Learning for Video MLLMs

[Read Paper](https://huggingface.co/papers/2608.20492)

OraRL improves reinforcement learning post-training for video multimodal language models by integrating oracle rollouts with decoupled advantage estimation and sign-balanced pruning, achieving higher sample efficiency and scalability without chain-of-thought generation.

### 2. GigaBrain-0.7: Scaling Embodied Foundation Models to Emergent Capabilities with a Three-System Architecture

[Read Paper](https://huggingface.co/papers/2608.15875)

GigaBrain-0.7 is a vision-language-action model that improves embodied generalization via a three-system architecture, large-scale heterogeneous pretraining, and joint alignment training.

### 3. WeMM-Embedding: WeChat Multi-Modal Embedding Technical Report

[Read Paper](https://huggingface.co/papers/2608.24053)

WeMM-Embedding is a family of universal multimodal embedding models that align text, images, videos, and interleaved inputs in a shared space, achieving state-of-the-art retrieval and recommendation performance across public benchmarks and large-scale WeChat applications.

### 4. AutoSaddler: Automatic Harness Optimization with Durable Updates from Agent Execution Traces

[Read Paper](https://huggingface.co/papers/2608.23041)

AutoSaddler automatically improves LLM agent harnesses via offline failure-driven optimization, boosting performance on long-horizon benchmarks.

### 5. On-Policy Self-Distillation in Diffusion Models

[Read Paper](https://huggingface.co/papers/2608.24646)

DiffusionOPSD uses on-policy self-distillation to turn image-level rewards into explicit intermediate targets for diffusion models, improving alignment efficiency and enabling separate analysis of target construction and policy fitting.

### 6. CyberFactory: Scaling Cyber Security Capabilities with Instances from the Wild

[Read Paper](https://huggingface.co/papers/2608.23181)

CyberFactory is an open-source framework that builds agentic training data from real vulnerabilities to train Aegis, improving open-weight cybersecurity performance across proof-of-concept generation, patching, and question answering.

### 7. Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses

[Read Paper](https://huggingface.co/papers/2608.24876)

Recuris introduces a recursive memory architecture that tracks progress and guides skill selection to improve long-horizon agent success through localized, validation-gated updates.

### 8. Best Practice Critic Optimization

[Read Paper](https://huggingface.co/papers/2608.23566)

BPCO stabilizes critic-based reinforcement learning for language models by combining bounded value predictions, Monte Carlo targets, and adaptive advantage estimation, matching group-based methods with single-response sampling.

### 9. On-policy Distillation with Verifiable Reward

[Read Paper](https://huggingface.co/papers/2608.24696)

OPDVR integrates on-policy distillation with verifiable rewards via a ReLU-gated implicit reward reformulation, improving reasoning performance without extra hyperparameters.

### 10. From Seeing to Acting: Smart Glasses as First-Person Intelligence Platforms

[Read Paper](https://huggingface.co/papers/2608.24877)

Smart glasses are surveyed as unified first-person intelligence platforms requiring sustained perception-state-interaction-action loops across constrained hardware and diverse applications.
